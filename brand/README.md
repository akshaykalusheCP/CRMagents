# Nimbus brand

**Nimbus: AI agents for Salesforce.**

## The mark
A cloud (*nimbus*) with a node beneath it: the record an agent works on, connected to the cloud. Plain geometry,
no sparkles. The same shape is in `apps/web/src/components/Logo.tsx` (`MARK_PATH`) and the favicon; keep them in step.

| File | Use |
|---|---|
| `nimbus-mark.svg`, `nimbus-mark-512.png`, `nimbus-mark-1024.png` | App icon, avatars, social profile pictures |
| `nimbus-mark-mono.svg` / `nimbus-mark-white.svg` | One-colour mark (print, watermarks, on photos) |
| `nimbus-logo-light.png` / `nimbus-logo.svg` | Mark + wordmark on light backgrounds |
| `nimbus-logo-dark.png` / `nimbus-logo-dark.svg` | Mark + wordmark on dark backgrounds |
| `nimbus-og.png` | Link previews (also served as `/og-image.png`) |

The SVG wordmarks use the Inter font by name; for print or design tools use the PNGs, or outline the text.

Tile gradient: 135°, violet → blurple at 60% → coral.

## Rules
- Clear space around the logo: at least half the tile's height.
- Don't recolour the tile, stretch it, add effects, or put the gradient tile on a busy photo (use the white mark).
- Wordmark: Inter Semibold, tight letter-spacing, "Nimbus" with a capital N only.
